[Fact index](README.md) · [Distribution ledger](distribution.md) · [Channel ledger](channels.md) · [Asset ledger](assets.md) · [Product ledger](product.md)

Observed **2026-10-26**, approximately **16:55–17:15 UTC** (12:55–13:15 America/Toronto). This is a public presentation audit, not an account-access or submission-console audit. English/default public pages were checked; private drafts, regional availability and every translated/device-specific variant remain unverified. No listings, accounts or other repositories were changed. Temporary image retrievals were used for visual inspection, byte hashes and dimensions; no media binaries are stored here.

## Coverage and evidence method

Direct HTTP HTML inspection established page text, linked assets, outbound destinations and response status. A search/browser retrieval was used when direct access was blocked, explicitly identified below. Eighteen unique image assets were fetched and visually inspected; three additional placements reuse already-inspected original URLs. SHA-256 values identify the bytes retrieved, not original capture date, copyright ownership or gameplay version. Dimensions are measured from files rather than inferred from HTML. Image descriptions below are visual observations; in-game interpretation and version attribution are separately qualified.

A successful HTTP response alone is insufficient: Debian returned a JavaScript challenge with HTTP 200. Conversely, HTTP 403/410 in this environment does not establish worldwide delisting or the absence of unpublished submissions. Publisher names and public maintainer identities below do not establish access by anyone in the current team.

## Observed consistency differences and remaining coverage

- **Product story:** modern homepage explains colony work, food and rival settlements; Snap foregrounds automatic task allocation; legacy wiki and distro descriptions retain LAN/YOG and scripting/editor context. These are observed presentation differences, not findings about which message works.
- **Visual story:** current homepage publishes clean world/replay scenes; legacy/wiki-derived catalogs publish window/HUD/fog screenshots, including an annotated battle; OnWorks includes menus/settings/results as well as battle. NeonRoof's three screenshot placements reference the exact wiki original URLs inspected above; its cover is a separate processed asset. No visual-quality ranking is implied.
- **Version story:** experimental 0.11.4.0 on current website, stable 0.11.2.0 on Snap, older 0.9.4.x/0.9.5-snapshot lines on other surfaces. OnWorks' visible 0.8.23 menu is direct evidence that a page's named download version is insufficient screenshot provenance. Screenshot filename/section labels also disagree within legacy wiki.
- **Destination story:** current homepage directs play to `app.glob2online.com`; Snap, legacy and several packaging/catalog records still direct visitors to the old domain. SourceForge and independent wrappers are not assumed controlled submissions.
- **Coverage still open:** every private submitted listing/draft, account/domain control, region/locale/device variants, complete SourceForge/AlternativeTo galleries, remaining distro catalogs (including Mageia), translated legacy galleries, detailed original capture provenance/rights, live store/install/device behavior, and the current availability of old YOG/community workflows. This bounded pass resolves exact public examples, not the full console-to-source estate.
