# Glob 2 Bot Cup campaign

A free JavaScript workshop for teens who have used conditionals and functions. Pairs edit one rule in a bot that runs a Globulation 2 colony, test its effect, and enter a private tournament. Lead with Ontario teen coding academies and camp operators. Invite a smaller group of high-school CS teachers to test classroom fit.

## How to judge the response

Aim for four substantive conversations and two concrete host commitments, including an academy. Count a commitment when a named cohort and instructor have a tentative date or a scheduled device rehearsal. Track replies and general interest separately.

- **Two commitments:** Book both pilots and use the same lesson and rubric.
- **One commitment:** Run that pilot and change one aspect of the offer based on the other conversations before approaching more leads.
- **Four conversations and zero commitments:** Fix the most common obstacle before sending a wider wave.
- **Fewer than four conversations:** Treat the first week as inconclusive and continue handling late replies.

At the pilot, aim for 80% of pairs to run a modified bot within 20 minutes of starting the edit, and for 70% to explain their change using evidence. Ask the host whether they would run it again and which cohort they would choose.

The kit has a verified native sample matchup. Confirm the workflow on each host's devices before booking student sessions.
