# Glob 2 Bot Cup

**Code a colony. See how it competes.**

In this free JavaScript workshop, teens change how a colony makes decisions in Globulation 2, an open-source strategy game. They test their change in the same matchup, explain the result, and enter their bot in a private group tournament.

| | |
|---|---|
| **Who** | Ages 13–17 who have used conditionals and functions. Students work in pairs. |
| **Time** | Two 60-minute sessions. |
| **What students learn** | Make and test a prediction, control experimental variables, debug a rule, and explain a trade-off using evidence. |
| **What Glob 2 provides** | A working starter bot, instructor checklist, setup rehearsal and tournament support. |
| **What the host provides** | An instructor, an approved device and editor for each pair, and two dates with the same group. |

**Session 1 — Change a rule.** Watch the starter bot run a colony. Predict what will happen if it aims for three inns instead of two. Make that edit in JavaScript and compare the two runs with the same map and opponent. Record one observed effect.

**Session 2 — Test and compete.** Try a different map, explain what happened, and hand in the bot. Watch a private round of matches. Recognize the best-supported explanation alongside the tournament winner.

A host can teach the workshop with manual edits. If the host allows a coding assistant, pairs can ask it for help and still explain the final change and test it themselves. For the planned local workflow, the instructor submits files using team aliases. The organizer returns the results privately through the instructor.

To try the pilot, tell us which group you have in mind and give us two possible dates for a 15-minute walkthrough or device rehearsal.
