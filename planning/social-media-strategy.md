# Globulation 2 social media strategy

Working plan drafted 2026-11-23. YouTube is the first new social channel. The publishing cadence and later channels are proposals. Track access, account creation and public verification in the channel inventory.

## Goals and channel roles

Turn discovery into a first browser session, help players get through the tutorial, and give returning players reasons to join multiplayer or share maps. Lead with the colony economy and expansion decisions. Use rivals and autonomous units to show the consequences of those decisions.

| Channel | Publishing role | Starting effort |
| --- | --- | --- |
| Website | Canonical play, download and community links. Link verified project profiles from the community page when they are ready. | Update when profiles or destinations change. |
| Discord | Community home for questions, match coordination, map sharing and release discussion. | Check the official server's announcement and moderation permissions first. Start with one discussion or event prompt every two weeks. |
| YouTube | Searchable tutorials, gameplay demonstrations and release videos. | Start with one tutorial or gameplay feature per month when footage and captions are ready. |
| Twitch | The official Globulation 2 channel is home to **Claude Plays Glob**, a 24/7 live colony RTS exhibition. | Feature one weekly challenge on the same feed. Promote it with the colony's objective and an actual gameplay moment. [Twitch plan](twitch-streaming.md) |
| Bluesky | Short clips, screenshots and development notes with a path back to play. | Try one post per week after ownership and profile setup. |
| Reddit | Participate in existing community discussions where the rules allow. | Share a meaningful update when relevant. Open a project subreddit when there is a moderator and recurring discussion to support it. |
| Facebook, Instagram, Mastodon, X and TikTok | Assess existing profiles and handle options as part of the account audit. | Add a publishing channel when an owner, content format and reason to reach its audience are established. |

| Days 31–60 | Rotate among colony decisions, map spotlights, replay breakdowns and release notes. Try a scheduled Discord match if a moderator can host. | Record which posts generate visits, play clicks and substantive player questions. |

For each release, use the project release notes to verify what players can access. A single capture can serve several channels. Use [the gameplay video guide](gameplay-video.md) to select developed colonies, active units and visible fighting for promotional clips. Publish a captioned clip with a play link, explain a decision the footage supports, and use Discord to invite discussion. Credit player-submitted maps or screenshots with the contributor's permission. Localize sustained formats first using the [existing translations](../translations/README.md) and a reviewer for each target language.

Use Twitch highlights for the next featured challenge and YouTube Shorts for a self-contained gameplay moment. Link to the live channel when the invitation is to watch. Use the browser play link when the invitation is to try Globulation 2.

## Account operation and handoff

Use a project-controlled mailbox where a platform supports it and individual delegated accounts where available. Confirm one accountable owner and one backup administrator. Verify both can perform the necessary admin or recovery action before relying on the channel. Keep shared sign-in material, recovery codes, private contacts and recovery instructions in the project's private vault. The public inventory should record the profile URL, ownership status, verification date and outstanding access gap.

Before announcing a profile, reopen it signed out and verify the name, handle, website and public visibility. Use the website as the canonical directory. Use native scheduling where useful and assign a person to handle replies, moderation and corrections. Route reproducible bugs through the existing issue tracker and private account issues through a private support route.

Review access quarterly and on maintainer transitions. In platform settings, remove departed maintainers' roles and verify that the primary and backup administrators can still access the channel.

## Measurement

Use aggregate daily or weekly data. For post links, set `utm_source` to the platform, `utm_medium=organic_social`, `utm_campaign` to the release or series, and `utm_content` to the asset or post identifier. Keep canonical profile links simple. Track post date, channel, format, topic, link clicks, browser play-link clicks when measurable, and meaningful Discord discussion or event participation. Treat tutorial completion or multiplayer activity as attributable only when instrumentation supports the connection. Record unavailable metrics explicitly.

Review monthly using the first four weeks as a baseline. Compare formats within each channel and report both volume and response per post alongside time spent. Use those results to choose the next experiment.
