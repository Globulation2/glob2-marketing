# Linux distro rollout

Baseline on 2026-11-23 is [Globulation 2 0.11.7.0](https://github.com/Globulation2/glob2/releases/tag/v0.11.7.0). The [engineering tracker](https://github.com/Globulation2/glob2/issues/1311) records native packaging work and downstream submissions. The [0.11.4.0 handoff](https://gist.github.com/genixpro/3970738a7a839b32b83db671db20545f) is prior evidence for recipe structure and upgrade tests. The first candidate builds use the published source tarball after the [CMake migration](https://github.com/Globulation2/glob2/pull/1645).

## First wave

Engineering retargeted the tracker to CMake and verified the published 0.11.7.0 source archive against SHA-256 `3dffe97a657a8025e48990e7f9581a2108ab81c5c67f8e54fa2b09052a20b5d6`. The draft system-FFmpeg change passed the fast gate. The full CI matrix reported a TLS failure when fetching web music and did not pass. [Engineering tracker](https://github.com/Globulation2/glob2/issues/1311) · [Draft build PR](https://github.com/Globulation2/glob2/pull/1893)

- **Arch x86-64 candidate.** Built offline from pinned v0.11.7.0 source and upgraded offline from Extra's `0.9.4.4-56`. `pacman -Qkk` found zero altered files across 63,440 files. A 128-tick reference run matched checksum `1cea58cc`, and removal preserved the user profile sentinel. The Arch dist-git change is staged locally and ready for packaging review. The submission route is a direct merge request to the existing Extra package repository. An Arch clean-chroot check and contributor account are still needed. [Extra packaging repository](https://gitlab.archlinux.org/archlinux/packaging/packages/glob2) [Successful build and verification](https://github.com/Globulation2/glob2/actions/runs/45310448986) · [Candidate artifact](https://github.com/Globulation2/glob2/actions/runs/45310448986/artifacts/14884252719)
- **Debian source package.** Built a local `0.11.7.0-1~glob2.1` source kit containing the `.dsc`, canonical upstream tarball, separate pinned encoder sources, and Debian diff. Regenerated the source kit with the corrected `/usr/share/games/glob2` data path and verified all three SHA-256 entries and sizes in the `.dsc`. The corrected native arm64 `glob2` and `glob2-data` packages built and installed offline. A 128-tick run outside the checkout located assets through the system path and matched checksum `1cea58cc`. The arm64 offline upgrade from official sid `glob2 0.9.4.4-11+b1` and `glob2-data 0.9.4.4-11` to `0.11.7.0-1~glob2.1` also passed. `dpkg -V` reported no integrity differences, the normal runtime matched checksum `1cea58cc`, and `dpkg --purge` preserved the user profile sentinel. [Engineering tracker](https://github.com/Globulation2/glob2/issues/1311)
- **SDL3_net.** The amd64 repository checks found SDL3_net on Debian sid, Ubuntu 26.10, Tumbleweed, Fedora 45, Fedora Rawhide, and Arch. Local SDL3_net 3.2.0 packages installed offline and passed compile, link, and initialization checks on Debian 13, Ubuntu 26.04 LTS, and Leap 16.0, where the repository checks found no provider. Debian 13 needed a local adjustment to the recipe's SDL3 version requirement. These targets still need a downstream dependency decision. [Engineering tracker](https://github.com/Globulation2/glob2/issues/1311)
- **Recording.** The focused system-FFmpeg test wrote and reopened a six-frame VP9/Opus WebM on Arch, Debian sid, Fedora 45, and Tumbleweed on amd64. Full candidate builds are running on Fedora 45 and Tumbleweed. [Draft build PR](https://github.com/Globulation2/glob2/pull/1893)
- **Upstream RPM compatibility.** The published Fedora 43 RPM installed on Fedora 45 with Fedora's OpenSSL 3 compatibility libraries and completed the 128-tick smoke with checksum `1cea58cc`. The native Fedora 45 candidate still needs whole-package testing. [Engineering tracker](https://github.com/Globulation2/glob2/issues/1311)

- **Gentoo dependency.** The checked Gentoo repository snapshot lacked SDL3_net. A draft SDL3_net 3.2.0 ebuild built and installed natively on Gentoo arm64, and `pkg-config` returned `3.2.0`. This was a local package. A Glob2 ebuild installation remains pending. [Engineering tracker](https://github.com/Globulation2/glob2/issues/1311)
- **Ubuntu candidate.** The native arm64 build for Ubuntu 26.10 is queued with the corrected system asset path. [Engineering tracker](https://github.com/Globulation2/glob2/issues/1311)

Official downstream submissions and packages remain pending.

Start the Tumbleweed, Arch, and Debian candidates in parallel. Use the Debian source package for Ubuntu compatibility builds while the Debian upload is pending. Fedora starts in Rawhide. Gentoo needs a CMake ebuild and a willing reviewer or proxy maintainer.

## Evidence and rollout

- **Glob2 engineering** owns source identity, shared CMake fixes, and the evidence for each candidate. Record clean build and package-manager installation, upgrade from the distro package where available, gameplay smoke, save/resume and replay checks, and removal with the user profile retained. Record architectures and exact package revisions. Keep the licensing and dependency decisions keyed to the source release.
- **Downstream maintainers** own acceptance and publishing. For each release, record candidate built, submitted, accepted, published, and installed from the official repository as distinct milestones. Link public build and review evidence as it becomes available.
- **Marketing** owns this ledger and launch copy. For each active target, update the version, latest verified milestone, public evidence, blocker, and next follow-up date when known. Use the [approved rollout](approved-storefront-rollout.md) for copy and imagery.
- **Website** adds a distro-specific install command and version after a clean machine can install and launch the published repository package. The [upstream release](https://github.com/Globulation2/glob2/releases/tag/v0.11.7.0) already provides direct-download Linux artifacts, including its Fedora 43 RPM, Ubuntu 22.04 tarball, Flatpak bundle, and Snap file. Link those artifacts under direct downloads.
