## Authorization and destination

On **2026-10-30**, the user requested switching `glob2online.com` to **`glob2.online`** across repositories, links and other uses, with the older domain redirecting to the new domain. This authorizes the corresponding maintained source, hosting and controlled-listing changes. It does not itself establish that DNS, TLS, application authentication or external publisher fields have migrated.

Use **`https://glob2.online/`** for the project website. The application destination is **`https://app.glob2.online/`**; its runtime migration is verified below. Website HTTPS readiness and old-domain redirects remain separate checks. Preserve paths and query strings when redirecting old public URLs; verify both HTTP and HTTPS, apex and `www`, and any existing application endpoints. An HTTPS redirect requires working TLS on the old hostname.
