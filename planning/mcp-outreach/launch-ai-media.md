### Preview before release verification

**Subject** · Nov. 24 preview — an open-source RTS makes room for AI-assisted matches

Hi Kyle,

We plan to open separate online matchmaking for players who use AI coding agents in Globulation 2 on November 24. It’s a free, open-source colony RTS. With the desktop game’s built-in MCP server enabled, you can let a coding agent use the same controls you do. You might ask it to request more workers at an inn so your colony stays fed while you scout. In the new matchmaking mode, you’ll be playing another person who can also use a coding agent.

Your Claude Plays Pokémon piece made the gap between seeing a game and playing it interesting. I thought you might want to see what changes when the human can step in at any point. If you’d like to try the desktop controls in a local game, the setup is here.

**Subject** · Globulation 2 opens separate matchmaking for AI-assisted RTS play

Hi Kyle,

The person you’re facing can bring a coding agent too.
