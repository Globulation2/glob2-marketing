# Globulation 2 first-touch outreach

[Research project](README.md) · [Product evidence](product-and-prior-art.md) · [Demonstration brief](demo-and-pitch-brief.md)

Drafted for Bradley Arsenault, Globulation 2. The set covers 16 recipients. Each message gives its recipient a concrete thing to try, report on, or discuss based on their published work. The copy uses a direct maintainer voice and gives recipients room to make their own judgment. The [launch dispatch log](launch-dispatch.md) records subsequent sends and the exact versions used.

## Pick the version that matches the release

**Online launch.** The project owner expects the public rollout overnight November 23–24, Toronto time. The pre-rollout check still returned the ordinary casual and ranked queues and desktop version 0.11.7.0. Use online-launch copy when the public client, mode and Internet match support the claim in that message. Pitch the narrower experience if the rollout offers only part of the proposed story. [Public instance configuration](https://app.glob2.online/api/v1/instance) · [Latest desktop release](https://github.com/Globulation2/glob2/releases/latest)

**Desktop hands-on.** The desktop game already offers optional MCP controls and JavaScript standing orders during a local match. Use this angle for developer experiments and design conversations. When a coding agent helps a player in an online match, describe the actual game controls it uses there. Local scripts and hosted Hive Mind have their own availability and controls. ## Before using a draft

- Check the indicated route and the [existing outreach ledger](../mobile-press-outreach.md) for a recent approach to the same outlet. Send one version through the most relevant route. Public mentions, newsroom tips and creator invitations have different expectations.
- Remove internal labels and replace only the marked details from actual evidence. The current public install and setup links work for the desktop angle. Use a recording or result only when it exists and matches the scope in the message. Name the public queue as it appears in the compatible client.
- Keep the individual hook and single invitation. Use terms a reader already uses. Explain MCP as the connection between a coding agent and the desktop game when writing to a strategy audience.
- Sign as Bradley. Use the game name **Globulation 2** on first mention. Preserve the recipient's freedom to test, criticize or decline an invitation.
