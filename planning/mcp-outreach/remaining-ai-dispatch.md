**Subject** · Nov. 24 preview — what a strategy game exposes over MCP

Hi swyx and Alessio,

We plan to open separate online matchmaking on November 24 for desktop players who enable MCP in Globulation 2, our free, open-source colony RTS. A player can ask a coding agent to raise an inn’s worker request while they scout. Online, the agent uses the game’s ordinary UI. Your interview with the MCP creators got into how you decide which tools to expose. Would this fit a short example of designing MCP tools around a person who’s still using the app?
