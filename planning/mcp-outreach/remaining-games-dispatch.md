**Subject** · Which part of running a colony would you hand to an AI?

```text
Hi Al and the Critical Moves team,

Your episode about whether balance can spoil a strategy game got me thinking about a different design question. Which part of running a colony would you miss if you handed it off?

I work on Globulation 2, a free, open-source RTS where you assign work and place flags while the colony’s creatures look after themselves. In a desktop skirmish, you can connect a coding agent and ask it to write a small, pausable JavaScript routine. It could keep the colony producing workers while you scout and decide where to expand.

On November 24 we plan to open a separate online queue for players using coding-agent assistance. The agent would use the normal game controls while its player faces another person. The local scripting example is already available and is a simple way to see how sharing control changes an opening.

Would the question of which jobs are worth keeping make a segment for the show? I can share the setup if it’s useful.
```

```text
For Sourav Rudra — a Linux RTS with a way to share the controls with an AI

Hi Sourav,

You covered what the open-source Xodus project was getting to work on Linux. I have a smaller Linux gaming story. In Globulation 2, our free, open-source colony RTS, the desktop game has a built-in Model Context Protocol server. A compatible coding agent can connect to it on the same machine, read the game and use its controls while you play. Where the AI model itself runs depends on the client you choose.

That interface is already available in the Linux build. In a local skirmish it also lets a player ask the agent to write a JavaScript routine, such as keeping worker production steady while the player scouts. We plan to open separate online matchmaking for MCP-assisted play on November 24. There the agent uses ordinary game inputs, alongside a human player.

If that’s a fit for It's FOSS, I’m happy to share the confirmed rollout details when they’re available.
```

**Subject** · Developer article proposal — sharing the controls of a colony RTS with an AI agent

```text
Hi Holly,

I’d like to propose a programming article from our work on Globulation 2, an open-source colony RTS. Game Developer has covered the tools available for building multiplayer bots. Our design question is what happens when a human and a coding agent act for the same player.

The game’s optional desktop MCP server lets the agent inspect and operate the same interface as the person playing. A local match can also run a JavaScript standing order the player can pause. The piece would follow one concrete job, like staffing an inn, and show which commands we let an agent issue and where the game enforces its usual rules. The source and tool contract are public.

We plan to open separate matchmaking for MCP-assisted play on November 24. That gives the design a multiplayer question too. How do you offer this kind of play to people who want it while keeping ordinary matchmaking available?

Would a short outline fit your developer-authored programming section?

Bradley Arsenault
Globulation 2
https://glob2.online/learn/mcp-agent-tools/
```
