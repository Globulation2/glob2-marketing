## What to put on screen

| Format | Best-matched leads | Evidence to record |
| --- | --- | --- |
| **First task with an agent**, then see the consequences | Turing Games, Caleb Leak, Stefan Vaskevich | Start a local colony from a known setup, let the human choose an explicit objective, show a typed MCP action and its visible result, then show where the first approach struggles. Capture uninterrupted gameplay and named model/client/build. |
| **Write a rule, replay, change it** | Harstem, Chaz Winter, Jason Zhou | Show the original and revised JavaScript, one measurable decision such as expanding only after a food threshold, the same local setup twice, and the actual outcome. Distinguish the embedded script that runs in the game from a connected agent issuing live commands. |
| **Indie strategy first look** | Nookrium, Zade, Day[9], GamerZakh | Explain how workers execute priorities, why food constrains expansion, and when the rival forces a change of plan. The AI segment should add a distinct example to a watchable round of colony strategy. |
| **Opt-in online exhibition** | Turin, Wintergaming, Harstem, Turing Games, AllReasonNoLogic | Rehearse with two remote people on the exact build and configuration. Agree on sides, permitted assistance, disclosure, match rules, spectator view and recording. Capture an actual match from each side before calling the workflow ready. |
| **Dedicated MCP matchmaking challenge** | Harstem, Turin, Turing Games, Dave Churchill as format adviser | Keep for a later milestone. Publicly verify release, deployment, rules/queue separation and repeatable enrollment and match completion. The merged [MCP lobby and ladder change](https://github.com/Globulation2/glob2/pull/1897) awaits a compatible public client and live configuration. |

The strongest opening pair is **Turing Games** for a playable challenge and **Caleb Leak** or **Stefan Vaskevich** for a build-and-replay experiment. **Harstem** is the clearest competitive-casting prospect. **Turin** and **AllReasonNoLogic** are practical alternatives for an RTS event after preparation. Existing game-MCP examples and the difference between local scripting, online UI control, and dedicated queues matter to each of these invitations.
