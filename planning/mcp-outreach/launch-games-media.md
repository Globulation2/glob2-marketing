### Launch

**Subject** · For James Bentley — a free RTS opens matchmaking for players using coding agents

Hi James,

Globulation 2, a free, open-source colony RTS I work on, has opened a separate online matchmaking queue for people who play with coding-agent assistance. You covered a coding agent helping bring Command & Conquer to iPhone. In Globulation 2, the agent can help during the match itself.

You and the agent share a colony. You might scout the edge of the map while asking the agent to request more workers at an inn so the colony has enough food. The desktop game exposes its ordinary controls to the agent through Model Context Protocol (MCP). In a local match, you can ask the agent to write a small JavaScript routine that keeps doing a recurring job while you play.

The [desktop MCP guide](https://glob2.online/learn/mcp-server/) explains how the connection works. If you’d like to try the online setup firsthand, I can help arrange a match.

Bradley Arsenault, Globulation 2

### November 24 planned-rollout preview

**Subject** · For James Bentley — a free RTS plans a separate queue for AI-assisted play

Hi James,

I work on Globulation 2, a free, open-source colony RTS. We plan to open separate online matchmaking for players using coding agents on November 24. You covered a coding agent helping port Command & Conquer to iPhone. Our experiment puts the agent in the game with the player.

The player still controls the colony and can ask the agent to take a job, like requesting more workers at an inn while they scout for food. The agent connects to the desktop game through its built-in Model Context Protocol (MCP) server and uses ordinary game controls. The desktop connection is already available, and a local match also lets you ask the agent to turn one recurring job into a pausable JavaScript routine.

The [desktop setup guide](https://glob2.online/learn/mcp-server/) and [matchmaking implementation](https://github.com/Globulation2/glob2/pull/1897) are public. I can send the released build and confirmed queue details once the rollout is live.

Bradley Arsenault, Globulation 2

[Official site](https://glob2.online/)
