**Subject** · Could a coding agent learn to keep a colony fed?

Hi Caleb,

In your Godot experiment with Momo, Claude Code started improving the games once it could playtest its own changes. I'm working on a similar feedback loop for players in Globulation 2, a free, open-source colony strategy game.

A coding agent connected to the desktop game over MCP can inspect a local match and write a small JavaScript standing order. You can watch it run while you play, then try changing the rule. On November 24, we're aiming to open separate online matchmaking where players can share the live game controls with an agent against another person. The standing-order experiment runs locally.

Would you be up for trying the same opening twice and revising one rule between runs? You can pick the rule and the compatible coding agent. I'm happy to help with setup.
