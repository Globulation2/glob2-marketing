## Glob2 capabilities and availability

| Claim | Evidence and limit | Language for outreach |
| --- | --- | --- |
| Globulation 2 is a free, open-source colony-building RTS. | The public site describes indirect control: assign workers and place flags while globs find routes, gather and meet needs. It dates the project to 2004. [Official site](https://glob2.online/) | “An open-source colony RTS that has been growing since 2004.” |
| A coding agent can operate the game through built-in MCP. | Native desktop Windows, macOS and Linux have an opt-in loopback server. Human input stays active and the player can revoke the agent's control. The MCP server appeared in public 0.11.4.0, and 0.11.6.2 added map-tile gameplay tools. The latest public download checked was 0.11.7.0, published November 22. The MCP server is desktop-only. [MCP setup](https://glob2.online/learn/mcp-server/) · [Tool reference](https://glob2.online/learn/mcp-agent-tools/) · [Current release](https://github.com/Globulation2/glob2/releases/tag/v0.11.7.0) | “Connect a compatible AI coding agent to the desktop game through its built-in MCP server, and play the same colony together.” |
| The player can vibe-code a standing order for a local match. | The player can ask a coding agent to write a small JavaScript routine, hand it to the game through local Hive tools, and pause, resume or cancel it while playing. Local match scripting needs no Glob2 account or credits; the MCP client and model may have their own requirements. The local `game_*` and `hive_*` operations have a local-human-match boundary. [Automation overview](https://glob2.online/learn/automation-overview/) · [Released local scripting contract](https://github.com/Globulation2/glob2/blob/v0.11.7.0/docs/multiplayer/hive-mind.md#local-human-match-scripting-through-mcp) | “Describe a recurring colony job, let your coding agent write the JavaScript, and keep playing while the order runs in a local match.” |
| JavaScript AI opponents are a separate creative surface. | A custom controller can occupy an AI seat in local play, with versioned library releases and playtesting. Its code and role differ from a standing order for the human player. The online service advertising AI Studio is not evidence of custom scripts occupying an online match seat. [Player handbook](https://glob2.online/learn/javascript-ai/) · [AI library contract](https://github.com/Globulation2/glob2/blob/v0.11.7.0/docs/multiplayer/ai-library.md) | “You can also write and test a full JavaScript opponent for local skirmishes.” |
| The desktop UI tools can be used in an arranged online exhibition. | Project engineers drove two GUI clients through the embedded MCP server against a **local full online-platform stack**. This supports a controlled demonstration of ordinary UI interactions. A fresh public Internet match between two humans using MCP was outside this research pass. The structured local gameplay tools and scripts are not the online interface. [Engineering playtest receipts](https://github.com/Globulation2/glob2/pull/1845) · [MCP setup](https://glob2.online/learn/mcp-server/) | Arrange a private match with disclosed assistance and consenting participants. After a successful Internet rehearsal, describe the exact operating mode and match observed. |
| Separate MCP-assisted ranked and casual queues are implemented in source. | [PR #1897](https://github.com/Globulation2/glob2/pull/1897) adds separate quick-match queues and ladders for compatible clients that report MCP enabled, when configured by the operator. The change is outside release 0.11.7.0. The [production instance API](https://app.glob2.online/api/v1/instance) listed only `ranked-1v1` and `casual-1v1` at readback. Rooms, invites and LAN are outside this split. Self-reporting separates cooperating clients and does not prove an anti-cheat guarantee. [Matchmaking contract](https://github.com/Globulation2/glob2/blob/7e581709a759824176e89ebdb6ff50d19d4b8a14/docs/multiplayer/ratings-and-matchmaking.md#assisted-queues) | “Separate MCP-assisted quick-match queues are expected with the upcoming rollout.” For launch-day copy, name the modes visible to compatible players and verify the actual match flow. |
| Hosted Hive Mind is designed for natural-language support in online matches. | The [public Hive Mind guide](https://glob2.online/learn/hive-mind/) labels it coming soon. The production instance metadata advertised `commander`, a flag emitted when configured as enabled, which says nothing about who can actually use it. A signed-in player's entitlement, successful command in a live public build, and generally available credits/access were unverified in this pass. The source contract permits ranked on enabled instances and calls for staged enablement. [Instance API](https://app.glob2.online/api/v1/instance) · [Flag implementation](https://github.com/Globulation2/glob2/blob/v0.11.7.0/services/online/apps/api/src/publicFeatures.ts) · [Hive Mind contract](https://github.com/Globulation2/glob2/blob/v0.11.7.0/docs/multiplayer/hive-mind.md) | “The project is developing Hive Mind, a distinct in-game commander for natural-language orders during supported online matches.” |

The handbook MCP material describes 0.11.6.2. Link press to the pinned 0.11.7.0 desktop release as the reproducible build for this research. Current branch extras can differ. The project supports browser and mobile play, so show exact platform and version beside each piece of footage. If explaining why agent actions count like human inputs, demonstrate a rejected action under a normal game rule. ### Independent desktop smoke

The installed macOS 0.11.7.0 application reported revision `3194f85a5686`. It started in a temporary profile with the built-in MCP listener and a window at 1024 × 768. The check completed MCP initialization, listed 27 tools including `game_world` and `hive_program`, confirmed an available viewport, and read the real first-run UI with `ui_inspect`. The launch used reduced graphics and the portable SDL renderer to reach the endpoint within the probe window. This smoke covered connection and discovery. End-to-end agent co-play, a live model, scripting outcomes and Internet play were outside this check.

## Earlier and overlapping work

Search scope included November 2024 through November 2026, using MCP, model context protocol, desktop embedded/native, online multiplayer, co-play, RTS, programmable RTS, and examples by title. We compared publisher and research team pages, executable source and maker announcements. This is a counterexample search, since an exhaustive global priority claim would need substantially more evidence.

**Editorial conclusion.** Drop “the first game playable through MCP” and “the first MCP-playable RTS.” The stronger hook is that a longstanding, manually playable open-source RTS has made AI collaboration something players can try themselves. The concrete interaction is a player changing colony priorities while a coding agent handles one visible job. A verified two-human exhibition or launch of the separate queues is a fresh reporting event in its own right.
