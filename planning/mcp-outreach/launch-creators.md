### Planned November 24 rollout

**Subject** · Would your chat coach an AI teammate in a strategy duel?

Hi Morpheus and Unyx,

Your chess stream gave chat a say in how the models played. I'd like to try a twist on that with Globulation 2, a free, open-source colony strategy game I work on. What happens when the two people in the match each share their side with a coding agent?

The desktop game has a built-in MCP connection so a compatible coding agent can use the same game controls as the player. We're aiming to open separate online matchmaking for MCP-assisted play on November 24. In a duel, each player could give their agent one job, like adjusting worker requests at food buildings, while they decide where to expand. Chat could pick the jobs.

Would you be up for trying one match after the rollout? I can help with setup. You can choose how to divide the work and how much input chat gets.

Bradley Arsenault

## Caleb Leak

Use the email button on [Caleb's site](https://www.calebleak.com/). The site sets the public mail link in JavaScript. This is a separate local experiment for a creative coder and can go out independently of the online rollout. It refers to [Caleb's Godot experiment](https://www.calebleak.com/posts/dog-game/), in which the games improved when Claude Code could see the running game and test its changes.

**Subject** · Could a coding agent learn to keep a colony fed?

Hi Caleb,

In your Godot experiment with Momo, Claude Code started to improve the games once it could playtest its own changes. I work on Globulation 2, a free, open-source colony strategy game with a similar feedback loop for players.

In a local desktop match, a coding agent connected over MCP can inspect the colony and turn a request into a small JavaScript standing order. You keep playing while it runs. I’m curious what you'd change after watching a first attempt at keeping the colony fed.

Would you be up for trying the same opening twice and revising one rule between runs? I can help set up the game and you can pick the rule.

Bradley Arsenault
